To run the code follow below given steps:

1)  clone the repository
2)  Run command "npm install" for both backend and frontend folder to download the dependencies
3)  Add the secrets in the ".env" file
4)  Run command "npm run dev" on the terminal with frontend folder path to run the frontend
5)  Run command "nodemon server.js" on the another terminal with folder path of backend folder to start the server
6)  Open the browser and follow the link given on frontend terminal i.e "http://localhost:5173"
7)  You are good to go...
